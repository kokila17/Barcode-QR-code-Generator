# Barcode and QR Code Generator

This Barcode and QR Code Generator is a simple Java-based application that enables users to generate high-quality QR codes and barcodes (in Code 128 format) for any given input text or number. 
Built using the powerful ZXing (Zebra Crossing) library, the project provides an efficient and lightweight way to convert textual data into scannable visual codes that can be easily shared or printed. 
The generated codes are saved as PNG image files and can be used for various real-world applications like product labeling, digital links, inventory management, attendance systems, and more. 
The application runs from the command line, where users specify the input text and desired output image filename. This project is beginner-friendly and demonstrates practical implementation of external libraries in Java, image processing, and text encoding. It can be extended further into a graphical user interface (GUI) using Java Swing or integrated into larger systems for real-time code generation.


## 💡 Features

- ✅ Generate QR Codes
- ✅ Generate Barcodes (Code 128 format)
- ✅ Save generated codes as PNG images
- ✅ Simple command-line interface or GUI (optional)

## 🛠️ Technologies Used

- Java
- [ZXing](https://github.com/zxing/zxing) (Zebra Crossing) Library for QR and Barcode generation
